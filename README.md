# 2d-sprite-renderer
2D-sprite-renderer is a small JavaScript-library for drawing and animating 2D-sprites on a HTMLCanvasElement

The library contains five classes: ImageAsset (loads images), Sprite (drawable image), SpriteRegion (a region of a spritesheet), SpriteAnimation (imagesequences) and SpriteRenderer (draw everything on canvas).

## Installation
```bash
npm install github:m-mellin/2d-sprite-renderer
```
